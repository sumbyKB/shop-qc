# 故障排查手册（实战踩过的坑）

## 症状 → 原因 → 解法

### 打开商品页标题是 "Security Check"
- 原因：出口 IP 异常（机房IP/区域不匹配）或浏览器自动化指纹被识别
- 解法：① 确认出口 IP 国家与 URL 区域一致；② 确认是真实 Edge + CDP 附加而非 Playwright launch；③ 手动拖滑块一次（cookie 会持久化）

### 打开 /us/ 页面跳到当地商城首页（不是商品页）
- 原因：出口 IP 国家与站点区域不一致，TikTok 按地理位置强制重定向
- 解法：切对应国家的代理节点再试

### 抓到 999/1000 条左右卡住
- 原因：连续快速请求触发临时限流（约 20 个请求后），并非硬性条数上限
- 解法：v2 脚本已内置退避重试 + 星级分区；如果仍卡，把 `--page-size` 降到 20、请求间隔调大

### 接口一直返回 `{"code":100000}`（连页面自己发同样的请求也这样）
- 原因：**会话/IP 级限流**。典型诱因：反复用错误参数请求（如在错误标签页上抓另一个商品的商品ID）、短时间几十次调用。此时页面上评论卡片只有 SSR 内嵌的 ~3 条，翻页点了也没反应，看起来像"另一种页面模板"，其实是限流假象
- 解法：**停止请求 10-30 分钟再试**（脚本已内置：连续两次 100000 直接终止并诊断，不再傻等退避）。验证是否解封：对之前成功的商品重放一次，同样 100000 = 还在封；返回数据 = 已解封
- 预防：换商品抓取前确认标签页确实在目标商品页（脚本已按商品ID匹配页面）；控制请求频率

### 接口对**所有商品、所有会话**都返回 100000（含页面自己发的请求、UI 翻页点击无效、全新浏览器+新IP也无效）
- 原因：**TikTok 服务端故障/接口变更**（2026-10-09 下午实测：上午正常的接口下午全球性拒绝，前端自己的翻页也失效，移动端模板无替代数据源）
- 判别方法：对之前成功的商品重放 → 也 100000 + 页面自己点击翻页列表不变 = 服务端问题，**不是你的代码问题，等恢复即可**（低频探测，每 10 分钟一次单请求）
- 区别于会话级限流：限流通常换新 IP/新设备可解；服务端故障换什么都不行

### SSR 补充数据源（模板无关的免费加餐）
- PDP 的 HTML 里固定内嵌少量评论（`"product_reviews":[...]` 数组，通常 ~3 条）。脚本抓完 API 后会自动解析合并
- 注意：HTML 里的非 ASCII 字符是 `\uXXXX` 转义的，直接按中文/emoji 文本搜索会漏，要按 review_id/review_text 等 key 找

### page.evaluate(fetch) 一直挂起不返回
- 原因：无超时保护的 fetch 遇到服务端不响应
- 解法：脚本内已用 AbortController 15-20s 超时；若还挂，检查标签页是否被用户手动关闭/导航（重新 get_pdp_page）

### Playwright page.screenshot() 超时（waiting for fonts）
- 原因：字体加载事件在 TikTok 页面上不可靠
- 解法：改用 CDP `ctx.new_cdp_session(page).send("Page.captureScreenshot")`

### Python 控制台打印中文/emoji 报 UnicodeEncodeError
- 原因：Windows 控制台默认 GBK
- 解法：脚本头部 `sys.stdout.reconfigure(encoding="utf-8")`；或环境变量 `PYTHONIOENCODING=utf-8`；输出写文件最稳

### 页面上找不到评论元素 / 选择器全落空
- 原因①：body 不滚动，滚动容器是 `.overflow-y-scroll` div，要操作它的 scrollTop
- 原因②：列表虚拟渲染，元素滚到附近才出现在 DOM
- 解法：先滚到位再找；找分页行用"同一行 ≥3 个连续数字"的特征（注意末页数字会破坏连续性判断）

### CDP 9333 端口连不上
- 原因：Edge 没启动 / 端口被占 / 用了 Playwright 自带浏览器
- 解法：`netstat -ano | grep :9333` 查端口；杀掉旧 Edge 进程重启；确认命令行带 `--remote-debugging-port`

### 抓取的 JSON 里 has_more=true 但翻页无新数据
- 原因：排序波动导致跨页重复
- 解法：正常现象，按 review_id 去重即可（脚本已做）

## 合规提醒
- 仅抓取公开可见的评论数据，1.5s/请求限速，不对接口做压力测试
- 不绕过登录墙/付费墙，不抓个人隐私字段（脚本保留的 reviewer_name 是平台脱敏后的展示名）
- 遵守所在团队的数据使用规范，抓取数据勿对外再分发原始个人信息
