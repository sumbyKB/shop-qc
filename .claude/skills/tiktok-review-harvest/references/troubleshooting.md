# 故障排查

先保留错误提示与 JSON 的 status、stop_reason，不把“生成了文件”当作完整抓取。

## 找不到脚本或依赖

使用已安装 skill 的绝对脚本路径，优先使用 skill 的 .venv 中的 Python。
缺依赖时由 agent 按 [../INSTALL.md](../INSTALL.md) 创建或复用隔离环境，安装 requirements.txt 后继续。
没有 Python 时告知用户需安装 Python 3.10+。

## Edge/Chrome 未找到

设置 TT_BROWSER_PATH 为真实可执行文件路径；TT_EDGE_PATH 保留兼容。
不要指向快捷方式。机器需要图形桌面，Linux 还需浏览器运行依赖。

## 代理检测失败或出口国家不符

设置 TT_PROXY=http://127.0.0.1:<本机HTTP或mixed端口>。
能直接访问站点且国家一致时可用 TT_PROXY=direct。
自动端口探测不支持 SOCKS-only 或需要账号密码的代理。
既有浏览器按实际出口校验；切换节点后关闭本 skill 的浏览器再重试。

若 IP 查询服务不可用，只有用户手动核实实际浏览器出口正确后才能使用 --skip-ip-check；
这个选项不跳过商品 ID/区域校验或验证码。

## Clash 辅助脚本不能连接

新版不绑定 verge-mihomo 命名管道，需要 HTTP external-controller。
设置 CLASH_API/CLASH_SECRET，或直接在代理软件中手动切节点；
不需要为了抓取安装特定 Clash 客户端。401/403 通常需检查控制器密钥。

## CDP 端口冲突或无法启动

默认 9333，可设置 TT_CDP_PORT 为另一个空闲端口（1..65535）。
检查浏览器安装路径、独立配置目录的写权限及桌面环境。
只关闭本 skill 启动的独立浏览器，不结束用户其他浏览器。
TT_PROFILE_DIR 不要指定日常浏览器的配置目录。

## Security Check

手动在独立浏览器窗口完成验证，最多等待 5 分钟。超时后脚本停止。
验证码可能再次出现，持久化 cookie 不保证永久免验证。

## 商品页重定向

检查完整 URL 的区域与浏览器实际出口，确认最终仍是请求的商品。
脚本遇到区域/ID 不符会停止，不会将另一个商品的 SSR 评论混入报告。

## code=100000 或 HTTP 429

可能是限流、风控或接口问题，不能仅据此确认原因。
连续两次 100000，或一次 401/403/429 会停止所有星级请求。
等待后再由用户决定是否重试，不保证固定解封时间，不连续更换会话强行重试。
保留的 JSON 可能只有部分评论，报表会标记警告。

## has_more=true 但无新增数据

可能是分页重复或排序变化。两页连续无新增/空页时停止，并标记部分数据。
先检查数量与 stop_reason，不把去重后的少量数据当作完整结果。

## 接口结构改变

脚本检测 product_reviews/has_more 等关键字段并停止。
保留已有 JSON，检查当前页面实际响应，再更新接口参数或字段；
不要盲目重试旧请求，也不要仅凭错误码认定服务端发生全球故障。

## Excel 无法保存

关闭正在打开的目标文件，或通过 report <JSON> --xlsx <新路径> 选择新文件。
父目录会自动创建。默认报告与 JSON 重跑时加后缀，不覆盖前次文件。
显式 --xlsx 会写入所指定路径。

## 报表显示“完整性未验证”或“部分数据”

查看 JSON 的 status、harvested_count、total_reviews_claimed、star_filter_totals、
stop_reason。无平台总数或数量不一致时无法认定全量。
报表返回 0 仅表示成功生成报表；抓取 all 返回 4 表示样本不足或完整性未知。
