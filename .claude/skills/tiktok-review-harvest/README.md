# TikTok Shop 评论抓取与分析

安装本 skill 后，直接在 Codex 或 Claude Code 中提交商品链接和分析要求。
AI 会执行环境检查、评论抓取和报告生成。

## 从 GitHub 安装

向 AI 助手发送：

> 帮我安装 https://github.com/sumbyKB/shop-qc 中的 tiktok-review-harvest skill，
> 路径是 .claude/skills/tiktok-review-harvest。

由宿主的 skill 安装功能完成安装。安装后重新加载技能，必要时重新打开宿主。
已经安装过的用户直接使用下面的示例。

## 使用示例

**抓取评论并生成报告：**

> 使用 tiktok-review-harvest 抓取这个商品的评论：<完整商品链接>。
> 生成 Excel 报告，并说明抓取是否完整。

**重点分析差评：**

> 分析这个商品的差评：<完整商品链接>。
> 总结用户不满意的原因、涉及的 SKU，以及可以改进的方向。

**指定保存位置：**

> 使用 tiktok-review-harvest 分析这个商品：<完整商品链接>。
> 将原始评论和 Excel 报告保存到 <我的工作目录>。

**分析已有数据：**

> 使用 tiktok-review-harvest，根据 <已有评论 JSON 的文件路径> 生成 Excel 报告。

请把占位内容换成真实链接或路径。商品链接需是完整的
https://shop.tiktok.com/<区域>/pdp/.../<商品ID>，不支持短链。
也支持印尼站 https://shop-id.tokopedia.com/pdp/<商品名称>/<商品ID>，自动识别为印尼区域。
纯商品 ID 默认美国站；其他站点请同时说明区域，例如“这是泰国站商品”。
Codex 可使用 $tiktok-review-harvest 显式调用。

## 首次使用会发生什么

1. AI 检查 Python 和依赖，缺少 Python 库时创建隔离环境并安装。
2. 自动寻找 Edge/Chrome，检查目标商品区域与网络出口。
3. 打开独立浏览器，抓取评论并生成报告。
4. 告诉你文件保存位置、抓取数量和完整性状态。

电脑需已有 Python 3.10+、Edge 或 Chrome、可访问目标区域的网络和图形桌面。
Windows 是主要支持平台；macOS/Linux 提供浏览器探测，仍需在目标机器预检。

如果出现 Security Check，请在打开的浏览器窗口手动完成验证码。
脚本最多等待 5 分钟。验证码、限流或接口变化可能影响抓取，不能保证每次获得全量数据。

## 网络配置

默认自动探测常见本地 HTTP/mixed 代理端口，无可用端口时尝试直连。
代理客户端不限于 Clash。

非标准端口可以直接告诉 AI：

> 我的 HTTP 代理是 http://127.0.0.1:8888，请用它运行这个 skill。

能直接访问目标站点时，可以告诉 AI“使用直连”。
美国站商品需要美国出口，泰国站需要泰国出口，以此类推。
shop-id.tokopedia.com 商品需要印尼出口；纯商品 ID 指定印尼区域时也使用该域名。
SOCKS-only 和需要账号密码的代理不支持，请使用代理客户端提供的本地 HTTP/mixed 端口。

切换代理后需要关闭本 skill 的独立浏览器，再重新运行。
AI 会检查浏览器实际出口；修改全局代理节点前会确认你的授权。
高级配置见 [环境配置说明](INSTALL.md)。

## 输出内容

Excel 包含 5 个工作表和 7 个图表：

| 工作表 | 内容 |
|---|---|
| 总览 | 评论数量、评分、星级分布、带图和购买标记 |
| 月度趋势 | 评论数量和平均评分随月份变化 |
| SKU 分析 | 各规格评论量与平均星级 |
| 差评分析 | 1–2 星评论、英文高频词及明细 |
| 评论明细 | 星级、日期、规格、评论内容、图片链接等 |

同时保存原始 JSON，方便后续重新分析。
图片以链接输出；日期统一使用 UTC；差评词频只分析英文文本。
具体保存位置由 AI 在完成后告知，默认放在当前工作目录的 output 和 report。
重复运行保留之前的默认输出；明确指定报表文件路径时可能覆盖该文件。

## 如何判断结果

- complete：已核对抓取时平台声明的总数和各星级数量。
- partial：中途停止或数量不足，报告只代表已抓到的样本。
- unknown：没有足够信息确认完整性，不能称为全量。

生成 Excel 成功不代表抓取完整，AI 会结合 JSON 状态说明。
网站限流时会停止请求，保留部分数据，不承诺固定解封时间。
Tokopedia 页面内嵌评论可作为样本保留，并记录页面声明的评分和总数。
这些样本不代表评论翻页已成功，仍需通过验证码及实际接口验证才能确认完整抓取。

## 遇到问题

直接把错误提示告诉 AI，让它按 [故障排查](references/troubleshooting.md) 处理。
常见情况包括缺浏览器、代理区域不符、验证码未完成、限流或 Excel 文件被占用。
依赖和路径问题由 AI 检查；验证码需要你手动处理。
